## 🏗️ My Engineering Philosophy

I prefer systems that are:

```text
Simple        → when complexity isn't necessary
Modular       → when components need independent evolution
Observable    → when something can fail
Typed         → when correctness matters
Testable      → before production
Secure        → by default
Automated     → whenever humans repeat the same task
Recoverable   → because failures are inevitable
```

I don't believe an LLM magically makes a system intelligent.

**The architecture around the model is what makes the system useful.**
